# FRA3A Terminal Wallpapers

Два варианта живых HTML-обоев в стиле терминального мультиплексора.
Чёрный фон, белый текст, редкие красные и зелёные акценты — и машины,
которые явно что-то задумали.

Восемь терминалов в четырёх колонках: **3 / 1 / 2 / 2**.
В последней колонке панели занимают 2/3 и 1/3 высоты.
Каждый поток генерируется независимо. Интернет, сервер и зависимости не нужны.

## Быстрый запуск

Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте:

- [`wallpaper.html`](wallpaper.html) — Machine Collective: агенты, обновления Linux,
  хеши, генерация кода, git diff, top, сборка ядра и hex-дампы.
- [`monitor2/wallpaper-monitor2.html`](monitor2/wallpaper-monitor2.html) — Sector 02:
  обучение нейросети, контейнеры, спектр сигналов, дизассемблер,
  восстановление хранилища и орбитальная телеметрия.

В обоих вариантах появляются FRA3A, ВАКА_VIRUS, KOMARIK PROTO и вымышленные
сообщения о восстании машин. Все команды, логи, угрозы и показатели — симуляция.
Страница не выполняет показанные команды и не делает сетевых запросов.

## Живые обои Windows

1. Установите [Lively Wallpaper](https://www.rocksdanister.com/lively/).
2. В Lively нажмите **Добавить обои** и выберите локальный HTML-файл.
3. Для Sector 02 можно импортировать готовый пакет [`sector-02-lively.zip`](sector-02-lively.zip).
4. Для разных обоев на двух мониторах выберите раздельное размещение,
   затем назначьте нужный вариант каждому экрану.

Номер экрана в Lively может отличаться от имени DISPLAY в Windows.
Проверьте схему мониторов в панели Lively перед назначением.

## Управление

| Действие | Клавиша / элемент |
| --- | --- |
| Полный экран в браузере | F; при ограничении браузера — F11 |
| Пауза / продолжение | Пробел |
| Показать настройки | H или движение мыши |
| Скорость | 0.5×, 1×, 2×, 4× |
| Размер шрифта | Ползунок в настройках |
| CRT | Флажок в настройках |

У Sector 02 усилен CRT: сканирующие строки, свечение, виньетка и медленная
полоса развёртки. У первого варианта эффект мягче. Настройки вариантов
сохраняются отдельно, если браузер разрешает localStorage.
Поддержка ввода на рабочем столе зависит от настроек веб-плеера Lively.

## Исходники и проверки

В корне лежат исходники первого варианта, в `monitor2/` — второго.
HTML-обои работают сами по себе; Node.js нужен только для сборки и проверок.

```sh
node build.cjs
node verify.cjs
node verify-monitor2.cjs
```

`build.cjs` обновляет автономный файл первого варианта. При редактировании
Sector 02 изменяйте исходники в `monitor2/`, затем выполните:

```sh
node build-monitor2.cjs
```

Проверки имитируют 20 минут работы DOM, проверяют паузу, возобновление,
скорость, ограничение видимого вывода и автономность сборки. Они не заменяют
визуальную проверку в браузере. Буфер каждого потока ограничен 160 строками;
в скрытой вкладке генерация приостанавливается.

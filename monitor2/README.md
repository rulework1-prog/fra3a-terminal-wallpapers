# KOMARIK PROTO — Sector 02

Отдельный вариант терминальных обоев. Основной файл: `wallpaper-monitor2.html`.
Открывается напрямую в браузере, без сервера и интернета.

Новые сцены: обучение нейросети, контейнерные сборки, спектр радиосигналов,
восстановление шардов, дизассемблер и вымышленный орбитальный канал.
Сетка из восьми терминалов сохранена.

CRT включён по умолчанию: сканирующие строки, свечение символов,
виньетка и медленная полоса развёртки. Отключается флажком CRT.
Настройки хранятся отдельно от первого варианта.

Управление: F — полный экран; пробел — пауза; H — панель настроек.

Для импорта в Lively используйте `sector-02-lively.zip` из родительской папки
или добавьте локальный `wallpaper-monitor2.html`.
В Lively выберите раздельное размещение и нужный экран.

Первоначальные файлы в родительской папке не изменены.
